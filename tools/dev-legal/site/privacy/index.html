Privacy Policy

隐私政策

生效日期：2026-11-15 适用：Worlds of Book 开发测试工具

1. 我们是谁

本政策适用于 Worlds of Book 的内部开发 / 测试工具（例如发帖通路验证）。 这些工具帮助项目成员确认官方发帖 API 是否配置正确。

2. 我们处理哪些数据

为实现授权发帖验证，工具可能处理：

  • 你在 OAuth 流程中授权后提供的 access token / refresh token / open id；
  • 与发帖相关的基础创作者信息（如平台返回的用户标识、公开资料字段）；
  • 你主动提供的测试文案、测试图片或其公网 URL；
  • 验证结果日志（成功 / 失败步骤、错误码），用于排障。

我们只请求发帖相关权限，不会为通路验证索取与发布无关的敏感权限。

3. 数据用于什么

  • 代表你已授权的账号调用官方 API，完成通路验证；
  • 在本机或项目约定环境中保存凭证，避免重复授权；
  • 排查集成问题（例如缺 scope、域名未验证、token 过期）。

4. 我们不出售数据

我们不出售、不出租、不向广告商提供你的平台令牌或账号数据。 除完成 API 调用所必需的第三方平台（TikTok、Meta、X 等）外，不会把令牌提供给无关第三方。

5. 存储位置与期限

通路验证工具默认把凭证保存在开发者本机（例如本地 .env / .data/credentials.json），不会提交到 Git。 Token 的有效期遵循各平台规则；过期后需刷新或重新授权。 当你撤销授权或提出删除请求时，维护者应删除本地保存的相关令牌。

6. 可撤销授权与你的选择

  • 在对应平台的应用授权设置中撤销访问；
  • 删除本机凭证文件或在工具中覆盖清空；
  • 联系维护者协助删除仍保存在约定环境中的令牌。

7. 第三方平台

当你授权 TikTok、Meta、X 等平台时，其数据处理还受各平台自身隐私政策约束。 请同时阅读这些平台的开发者与用户隐私条款。

8. 变更

若工具收集范围或存储方式发生变化，我们将更新本页面并修订生效日期。

English summary

This policy covers Worlds of Book internal development / testing tools. We process OAuth tokens, basic creator identifiers, and test media you provide, solely to verify official posting APIs. We request posting-related permissions only, do not sell user data, store credentials locally for development, and you may revoke authorization at any time via the platform or by asking us to delete stored tokens.

隐私相关请求：通过本 GitHub 仓库 Issues 或项目内部约定渠道联系维护者。
