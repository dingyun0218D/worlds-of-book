生效日期：2026-11-15 适用：Worlds of Book 开发测试工具

1. 工具性质

Worlds of Book 提供的相关能力（包括但不限于发帖通路验证工具）是 内部开发 / 测试工具，用于确认抖音、TikTok、X、Facebook、Instagram 等官方发帖 API 在我们自己账号上是否可用。它不是面向普通消费者的公开社交产品。

2. 谁可以使用

仅限 Worlds of Book 项目成员，以及已明确获授权、使用自有平台账号进行联调的协作者。 你必须对所连接的第三方平台账号拥有合法控制权。

3. 权限与用途

当工具请求第三方平台授权时，通常仅涉及发帖 / 内容发布相关能力，例如：

  • 获取用于识别已授权创作者的基础信息；
  • 代表你已授权的账号发布测试内容（优先私密 / 仅自己可见）；
  • 验证媒体 URL、凭证与 API 通路是否正常。

我们不会借此权限从事与通路验证无关的批量营销、爬取或转售行为。

4. 可撤销授权

你可以随时在对应平台（如 TikTok、Meta、X）的授权管理页面撤销对本工具 / 应用的授权。 撤销后，工具不得再以你的名义调用需授权的 API。你也可以要求项目维护者删除本地保存的令牌。

5. 测试内容

验证过程可能产生带有明确测试前缀的帖子。请在验证完成后自行删除测试内容。 未通过平台审核的应用所发内容可能被平台限制为私密可见。

6. 免责声明

第三方平台的可用性、审核结果、配额与计费由其自行决定。本工具按「现状」提供， 不对平台侧拒绝、延迟或政策变更承担责任。你应遵守各平台开发者条款与社区规范。

7. 变更

我们可能更新本条款以匹配工具能力变化。更新后的版本将发布于本页面，并更新生效日期。
