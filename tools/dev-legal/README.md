# @wob/dev-legal

Worlds of Book **Official Website** + **Terms of Service** / **Privacy Policy** 静态页（同一 GitHub Pages，分 URL）。

| 路径 | 用途 |
|------|------|
| `/` | Official Website |
| `/terms/` | Terms of Service |
| `/privacy/` | Privacy Policy |

使用说明与部署步骤见 [docs/tools/dev-legal.md](../../docs/tools/dev-legal.md)。

```bash
npm run dev:legal
# http://127.0.0.1:4173
```
